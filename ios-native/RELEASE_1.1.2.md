# iOS 1.1.2 连续滑动切集

2026-10-15，版本 1.1.2 / build 4。全屏播放上滑下一集、下滑上一集，参考短视频的连续分页交互：画面随手指移动，松手后吸附到整页，距离不足时回弹，首尾集带阻尼。

## 播放交接

当前集及前后相邻集分别保留播放器，预加载到可显示的首帧，缓存范围限制为三集。切集不再先清空当前画面；进入尚未准备好的页面时保留真实封面，视频图层报告首帧可显示后才揭开封面。冷启动或网络较慢时会看到封面等待，不能保证网络请求始终零延迟。

切集保持静默，不主动弹出加载卡片、错误窗口或控制栏。轻点画面仍可查看状态及重试。进度条周边开始的拖动、选集 / 设置面板内的操作不会切集。横竖屏均可用；VoiceOver 提供上一集 / 下一集操作，减少动态效果模式取消松手动画。

## 真机验收边界

本版真机 UI 测试在启动前因设备锁屏而终止，没有执行测试，不能记作真机通过。上版的静默连播通过记录不能代替本次播放器交接改动的真机回归。当前证据为模拟器行为与录屏验收、真机签名构建和设备安装；真机的连续播放及滑动体验仍需解锁后验证。

滑动用例单独关闭自动连播，避免等待检查期间剧集自然结束影响首尾集断言。自动连播使用独立用例，从第一集零秒自然播完，不快进、不暂停、不改倍速。此前简单滑动版的退出点击竞争与一次自动连播干扰失败结果也保留，不计入当前版本通过次数。

保留默认全屏、横竖屏按钮、断点续播和自动连播；本次不更换播放接口或播放器依赖，不改变 Android 发布与更新渠道。
