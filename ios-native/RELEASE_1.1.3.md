# iOS 1.1.3 请求恢复与滑动修正

2026-10-17，版本 **1.1.3 / build 5**。已对照 `hongguo-drama v1.73` 最新源码；访客签名接口未改变，本次重点是内容和媒体 GET 请求的有限恢复。

## 改动

- HTTP 408、500、502、503、504 或短暂连接中断时，最多发送三次 GET 请求，退避 300、900 毫秒；取消任务会立即阻止后续重试。分段请求保留原 URL、Range、画质和完整性校验。
- 请求层不重放 POST，不循环尝试明确证书拒绝、超大响应、其他 HTTP 4xx 或携带 `Retry-After` 的失败响应。最终失败仍能在既有界面重试；自动连播和滑动加载不增加窗口。
- 修正控制栏可见时滑动可能中断的问题：手指拖动期间控制栏只变透明，结束后再隐藏；自动隐藏计时与退到后台时的拖动状态同步清理。

## 本地验证

- 核心包 17 项：16 项通过，1 项实时接口测试按默认开关跳过。故障回归覆盖连续 HTTP / 传输失败、次数耗尽、取消、POST、证书、响应大小与服务器退避边界。
- 显式开启实时接口测试：真人短剧《雾锁情迷》与漫剧《谁让这个文盲修仙的第五季》取址、媒体索引及解密头读取通过。所测片源不代表全站覆盖。
- iOS 26.5 模拟器漫剧播放及选集通过，17.729 秒；最终滑动回归通过，56.253 秒，包含上下滑、横屏、三次切集后画面像素检查、进度条保护、控制栏可见时下滑、首尾集边界、后台返回保持暂停及退出后恢复竖屏。
- 首轮模拟器中，漫剧进入详情的点击时机与控制栏可见时下滑两项失败；前者沿用既有详情导航重试方式，后者修正播放器手势。失败结果保留，未计入通过次数。
- Xcode 本地真机目标构建成功，开发签名严格验证通过，包内版本 1.1.3 / 5。
