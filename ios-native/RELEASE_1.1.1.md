# iOS 1.1.1 静默连播

2026-10-14，版本 1.1.1 / build 3。自动进入下一集时保持安静，不主动弹出播放窗口或控制浮层。

自动切集沿用现有预取、解密与 AVPlayer 播放链，并标记为静默连播。控制栏保持隐藏，不显示居中的加载卡片或错误弹层。用户轻点画面后，加载或错误信息显示在控制栏内，可直接重试；手动选集、下一集、方向切换与播放设置保留正常交互。

## 回归方法与范围

`testAutomaticContinuationDoesNotPresentOverlays` 从真实首页进入详情和播放器，再通过选集显式选择第一集。自动连播阶段不点击、暂停、拖动进度条或改变倍速，仅等待真实播放结束并检查实际集数与界面。用户收藏及观看记录保留。

初期 UI 自动化连接问题已恢复。此前快进脚本曾有 2 轮通过、1 轮因拖动未生效而等待超时；后续准备状态与控制栏的脚本调整也出现失败。最终移除快进操作，以自然播放用例重新取得旧版失败、新版通过的证据，因此不将这些尝试写成连续三轮通过。历史日志保留在本机。

本轮验证正常播放的自动切集和手动下一集；没有注入断网或片源失效。异常时不主动显示弹层的分支已保留，用户仍可轻点画面查看状态并重试。本次未改变默认全屏、横竖屏功能或 Android 更新渠道。
