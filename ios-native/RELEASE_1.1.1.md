# iOS 1.1.1 静默连播

2026-10-14，版本 1.1.1 / build 3。用户要求连续播放时静默，不弹出窗口。

自动进入下一集时，使用现有预取、解密与 AVPlayer 播放链，并标记这次切集为自动连播。控制栏保持隐藏，不显示居中的加载提示或错误弹层。用户轻点画面后，加载或错误信息显示在控制栏内，可直接重试；手动选集、下一集、方向切换与播放设置继续保留正常交互。
