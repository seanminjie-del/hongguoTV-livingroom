# iOS 1.0.0 验证记录

日期：2026-10-14。构建：Xcode 27.0，最低目标 iOS 17；验收设备为实体 iPhone 16 Pro Max，iOS 27.2。

## 核心与实际接口

`HONGGUO_LIVE=1 swift test --package-path ios-native`：12 项测试全部通过。

- 签名匹配已固定的独立 JavaScript oracle；实时时间毫秒整数回归通过。
- SM3 标准向量、NIST AES-CTR 任意未对齐区间与加密子样本通过。
- MP4 恢复原始 AVC 编码，拒绝截断辅助索引与超限索引。
- 搜索归一化、剧名优先与去重；拒绝错集与不兼容 ByteVC2。
- Range 必须符合 HTTP 206、请求范围、总长和实际长度。
- 临时 TLS 失败仅为 GET 有限重试一次，POST 不重复；没有忽略证书校验。
- 实际短剧「首辅娇娘」69 集：960P、8,323,583 字节。实际漫剧「聚宝仙盆之杂灵根才是真BOSS第十三季」222 集：1080P、28,974,608 字节。成功取址、读取和解密文件索引。
