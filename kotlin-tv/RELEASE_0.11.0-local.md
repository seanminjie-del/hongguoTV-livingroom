# 红果 TV 0.11.0-local 交付与验证

2026-10-14。用户从三张概念首屏中选择 C「题材频道」，本版将它实现为可安装的原生电视客户端。保留 Kotlin 原生 View、OkHttp、Media3、红果品牌和已有播放/片单功能。公开仓库：https://github.com/seanminjie-del/hongguoTV-livingroom。

## 本版变化

- 首页左侧题材频道、右侧单频道海报墙。标准 1920×1080 首屏七列两排，共 14 张完整剧卡；少内容频道五列放大真实封面，大字号五列并保证选中卡片完整可见。
- 热门包含全部已载入剧集，题材从全部真实 tags 匹配，允许同一剧进入多个频道，频道内按 ID 去重。当前首页漫剧 60 部、短剧 72 部，不将首屏或首页来源当作平台全站片库。
- 频道上下经过只移动焦点，确认后才切换；右键进内容、第一列左键回频道。每频道独立记忆所选剧和纵向位置，详情、搜索、播放返回恢复位置。首页上键返回导航，下键再进原剧。
- 接着看、收藏有更新、稍后看作为有内容时的独立频道。续播确认直接播放；普通剧确认查看详情，菜单/长按管理片单，移除当前条目后保留可见焦点。
- 选中剧名称固定显示在海报墙上方，取消首页常驻简介。封面保持完整比例；标题和集数统一在封面下方，不遮住原画。
- 搜索独立于频道；结果数量与官网公开片库范围分开表达。分页固定可见，末排下键进分页、上键回结果；大字号减少到五列，类型开关在宽屏顶栏内，给封面留出空间。
- 左侧刷新/更多固定在底部，频道滚动区域只显示完整行，避免大字号末项被截断。焦点即时描边、100ms 明暗反馈，频道确认140ms淡入、纵向原生平滑滚动，动画可打断。

## OIL 设计评审

三张概念首屏 → 用户选C → 原生代表页 → 三轮隔离评审。先后修复分页裁切/遥控器跨区、接口文案、封面遮挡、少内容频道尺度、大字号频道裁切，并补齐分页获焦、五部频道、末项频道和第六部搜索结果的画面。

第三轮独立静态评审为 **7/10**，未达到9分目标；评分基于补验前截图，之后只补验了可见封面，不重打分。三轮已达上限。剩余差距是满内容首页的选中作品仍与邻卡等尺度：本版保留用户选择的高密度海报墙，以固定完整名称和珊瑚焦点识别对象；进一步放大主作品会占用邻卡空间，需要重新评估首屏密度和导航布局。未将这项差距说成已解决。

独立评审未能正常速度观看MP4，静态帧不作为动效手感通过；实际按键流程已由Instrumentation验证。实体电视远距离阅读、遥控器重复键手感及低内存长片单压力未现场验收。概念图里的生成封面没有进入客户端；客户端所有剧卡使用实际内容来源。

## 安装与构建

APK：`hongguotv-0.11.0-local-android8.apk`。包名：`com.hongguotv.nativeapp`，最低Android8。可使用同一Debug签名覆盖上一版本地包并保留记录；正式签名的同包名版本可能不能覆盖，应先备份片单。没有卸载实体电视应用或读取发布私钥。

需要JDK17和Android SDK36，在仓库根目录执行：

```sh
./kotlin-tv/gradlew -p kotlin-tv :core:test :app:assembleDebug :app:assembleDebugAndroidTest :app:lintDebug --console=plain
adb -s YOUR_TV install -r kotlin-tv/app/build/outputs/apk/debug/app-debug.apk
adb -s YOUR_TV install -r kotlin-tv/app/build/outputs/apk/androidTest/debug/app-debug-androidTest.apk
adb -s YOUR_TV shell am instrument -w com.hongguotv.nativeapp.test/com.hongguotv.nativeapp.TvAcceptance
```

验收会对该设备的本机片单执行可恢复的测试操作，只在测试设备运行。`-e scope large`只验大字号；`-e record true`从内容准备好后记录30秒流程。报告在应用external files/acceptance目录。源码ZIP由对应Git提交导出，不含本机SDK路径、缓存、依赖或签名材料。

实体电视安装/解码、Android8本轮运行、正式签名升级、全剧播放与红果App全站搜索尚未验收；当前为公开测试版，不配置自动更新渠道。
