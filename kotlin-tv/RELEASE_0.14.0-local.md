2026-10-17，版本 **0.14.0-local / versionCode 14**，最低 Android 8.0。

已对照 `hongguo-drama v1.73` 最新源码，播放接口实现相对先前适配没有变化。参考其有限重试与完整响应保护，为片库及媒体分段 GET 增加短退避：最多三次请求，等待 300、900 毫秒；临时 HTTP 408、500、502、503、504 与连接 / 读取中断可恢复。分段按原 Range 重取，重试保留清晰度、媒体校验与 Media3 预加载链。
