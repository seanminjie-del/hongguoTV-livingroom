# 红果 TV 0.12.0-local 自动更新验证

2026-10-14。公开仓库：[hongguoTV-livingroom](https://github.com/seanminjie-del/hongguoTV-livingroom)。APK 对应源码提交 `374ce115f266a087736e976b88dd223d91fb0ae6`，versionCode 12，Android 8 / API26 起可安装；使用与本仓库 0.10/0.11 相同的本地 Android Debug 测试签名。

## 使用

**先手动覆盖安装本版**，之后前台浏览时自动检查并下载本仓库新版，播放时不打扰。下载校验完成后选择「安装新版」，首次允许安装未知来源应用，再确认系统覆盖安装；不支持静默安装。设置 → 版本与更新可关闭自动更新或手动检查。

此前 0.10/0.11 指向原作者更新仓库，不能自动获取本仓库版本。其他签名的同包名应用不能直接覆盖，应先备份片单，避免卸载丢失记录。Release 设为 latest 供客户端发现，仍为测试签名，未配置云端正式签名发布。

## 实现

- 复用原有自动检查、下载、取消和安装流程；更新源改为当前公开仓库，兼容本仓库 tag / APK 命名，继续严格拒绝路径、查询参数和任意下载来源。
- 切换渠道清除旧渠道检查和延后提醒记录，保留用户的自动更新开关。
- 下载后校验大小、SHA-256、实际包名、版本、minSdk 和当前安装应用签名；同版本、回退版、换签名或损坏文件不能安装。
- 新增本地更新清单准备工具：验证真实 APK 与前版签名、递增版本并生成 update.json。只生成元数据，不读取私钥或自动发布。
- 公开 Release 提供 APK、对应源码 ZIP、update.json 和 SHA256SUMS。后续发布须保持签名与版本递增，具体见 [自动更新说明](AUTO_UPDATES.md)。
